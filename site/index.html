LOCAL RUST AGENT HARNESS

Local CLI harness for agents.

watf resolves an agent request against indexed command evidence. It keeps the plan as typed argv, validates the command surface, starts the process directly, and bounds stdout and stderr.

cargo install watf --version 0.0.1 --locked Read measured evidence

EXECUTION BOUNDARY

Execution uses structured argv.

  1. Resolve. Match the intent to bounded indexed evidence.
  2. Validate. Check the documented command and option surface.
  3. Execute. Spawn argv directly with an explicit directory and timeout.
  4. Return. Keep exit status and bounded stdout and stderr.

An ambiguous or unsupported request returns a compact abstention before process spawn. watf does not send generated text through a shell. Validation does not grant permission or prove that an action is safe. The calling agent must authorize execution first.

INSTALL 0.0.1

Install watf 0.0.1.

The crates.io package embeds 608 core records and needs no model. It does not contain the offline catalog. Install that data separately and rebuild the index when catalog search is required.

Direct CLI install

01 cargo install watf --version 0.0.1 --locked
02 watf index

Agent skill install

01 npx skills add sanix-darker/watf-skills --skill watf

The skill pins watf 0.0.1 and builds the default index when it is absent.
