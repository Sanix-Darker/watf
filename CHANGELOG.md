# Changelog

## 0.1.0 - source delivery

Initial offline Rust engine with bounded native ingestion, mmap capability index,
clause-aware cross-tool retrieval, budgeted evidence, foreground stdio API, typed
multi-step plans, documented-surface validation, safe literal rendering, optional
embedded Qwen3 inference and a minimal optional TUI.

Includes 124,530 provenance-backed catalog records, 608 bootstrap records, 100
complex evaluation inputs, 102 Rust test functions, an agent skill, installers,
Makefile, JSON schemas and CI/release/security/benchmark workflows.

Rust compilation, Rust tests, model inference and measured performance were not
verified in the assembly environment. This is not a tested binary release.
